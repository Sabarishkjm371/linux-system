# This readme file is about function pointers

### Where function pointers are used
1. Dynamic Runtime Linking
2. Signals
3. Process Management
4. Threads or multithreads
5. Device Drivers


### Things to remember
- Function name represents the base address of the function
- Function pointer holds address of a function, similarly how the int pointer holds address of a int variable
